# Unitree G1 IsaacLab Project

This repository records my experiments, notes, commands, reference files, and code modification patches for Unitree G1 standing and locomotion in Isaac Sim / Isaac Lab.

## Environment

- Ubuntu 22.04
- Isaac Sim 5.1.0 pip installation
- IsaacLab editable source installation
- Conda environment: `isaacsim`
- Robot: Unitree G1

## Local Repositories

- IsaacLab: `~/projects/IsaacLab`
- Unitree RL Lab: `~/projects/unitree_rl_lab`
- This project repository: `~/projects/unitree-g1-isaaclab-project`

## Current Goal

1. Understand how Unitree G1 is loaded in IsaacLab.
2. Understand G1 flat velocity locomotion task.
3. Identify rewards and configurations related to stable standing.
4. Run baseline G1 standing / locomotion experiments.
5. Later connect high-level VLA decisions to low-level velocity commands.

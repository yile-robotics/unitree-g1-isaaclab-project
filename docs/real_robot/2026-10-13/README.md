# 2026-10-13：AprilTag 几何审查与外参离线重算

本次没有重新采集、删除误差较大的验证点或覆盖旧结果。读取保存的代表RGB重新检测，
保留原关节角、指尖模型、板尺寸及fit/check分组，再分别求解和验证。

## 板的定义与代码修正

- 编号板为6×6，AprilTag 36h11，`marker_border_bits=2`。
- 大棕色方块55mm，横纵间隔17mm，中心距72mm。原点为ID0大方块外侧左上角，X沿列向右、Y沿行向下。
- 第r行、第c列中心为 `[c*0.072+0.0275, r*0.072+0.0275, 0]` 米。
- PnP使用编号中心的三维板坐标与二维像素坐标，不把检测四角直接当成55mm方块四角。
- 手触碰检测的布局/多尺度筛选统一使用对角线交点，避免与PnP所用中心定义不一致。
- 两套检测的缩放逆变换均修正为 `(corner+0.5)/scale-0.5`，计入半像素坐标关系。

只重算了已保存代表图；采集窗口中其他RGB没有全部保存，因此旧窗口诊断仍标记为原采集诊断，不能声称已重新验证全部时间窗口。
